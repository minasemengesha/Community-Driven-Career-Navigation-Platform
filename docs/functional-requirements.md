**Project:** Community-Driven Career Navigation Platform

## 1. Introduction

Functional requirements describe the services and
operations that the system must provide to its users.

## 2. Functional Requirements

| ID | Functional Requirement | Primary Actor |
| :--- | :--- | :--- |
| FR-01 | The system shall allow new users to register. | Guest |
| FR-02 | The system shall allow registered users to log in. | Registered User |
| FR-03 | The system shall provide a mechanism for registered users to recover access to their accounts. | Registered User |
| FR-04 | The system shall allow guests and registered users to browse available educational resources. | Guest, Registered User |
| FR-05 | The system shall allow guests and registered users to search for educational resources. | Guest, Registered User |
| FR-06 | The system shall allow registered users to vote for educational resources. | Registered User |
| FR-07 | The system shall allow guests and registered content creators to submit educational resource recommendations, associating guest submissions with their assigned guest identifiers. | Registered Content Creator |
| FR-08 | The system shall allow registered content creators to request the addition of new learning topics. | Registered Content Creator |
| FR-09 | The system shall provide access to informational pages, including About, Help, and Contact. | Guest, Registered User |
| FR-10 | The system shall allow promoters to submit requests for paid promotion of their content or platform. | Promoter |
| FR-11 | The system shall allow promoters to view the status of their promotion requests. | Promoter |
| FR-12 | The system shall allow customer support agents to review and verify promotional payment evidence. | Customer Support Agent |
| FR-13 | The system shall allow administrators to add, edit, delete, approve, and reject platform content. | Administrator |
| FR-14 | The system shall allow administrators to categorize, rank, and organize approved resource recommendations. | Administrator |
| FR-15 | The system shall allow administrators to manage reward points associated with registered users. | Administrator |
| FR-16 | The system shall allow authorized administrators to manage and send notifications to relevant users. | Administrator |
| FR-17 | The system shall allow the System Owner to view reports about platform performance, revenue, users, recommendations, and promotional activities. | System Owner |
| FR-18 | The system shall automatically generate and assign a unique guest identifier to unregistered visitors when they submit a resource recommendation, and use this identifier to detect and prevent duplicate recommendations for the same resource from the same guest identifier. | Guests |
| FR-19 | The system shall allow administrators to publish and manage platform announcements and advertisements. | Administrator |
