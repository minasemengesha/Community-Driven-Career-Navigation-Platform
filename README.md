# 🚀 Community-Driven Career Navigation Platform

A comprehensive web-based platform designed to guide software engineering students and tech learners toward the best learning resources, tutorials, and certifications. The platform operates on a crowdsourced recommendation model, backed by an administrative review and a built-in promotion system.

## ✨ Key Features

- Resource Discovery: Find top-rated YouTube channels and websites categorized by technology (e.g., HTML, PHP, MySQL) with free/paid certification details.
- Crowdsourced Recommendations: 
  - Guest Users: Can freely recommend useful learning resources.
  - Registered Users/Creators: Can submit recommendations to earn reward points.
- Admin & Support Management:
  - Manual review and ranking system for submitted resources.
  - Custom title requests for topics outside standard recommendations.
- Promotion & Payment System: Allows creators/platforms to promote their content via a secure payment upload and verification workflow handled by customer support agents.
- Interactive Pages: Includes About, Help, Contact, and dynamic popup announcements.

## 🛠️ Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Backend: PHP
- Database: MySQL
- Project Type: University Web Programming Course Group Project (6 Members)
